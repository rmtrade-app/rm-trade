RM TRADE website files

1. Upload index.html to the root of your GitHub repository named rm-trade.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait a few minutes for the Pages URL to appear.

Important:
- The registration form is currently a demo. It does not send personal data to Telegram.
- Do not collect real entries until a secure backend/Telegram integration is configured.
- The chart uses illustrative demo values, not live market data.
- The stated 92% success rate has not been independently verified.
